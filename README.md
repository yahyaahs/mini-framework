# Mini-Framework

A lightweight and simple framework implementation.

## Overview

This project is a minimal framework designed to demonstrate basic framework concepts and functionalities.

## Features

- Lightweight implementation
- Easy to understand
- Basic framework structure

## Installation

```bash
# Clone the repository
git clone https://github.com/yahyaahs/mini-framework.git

# Navigate to project directory
cd mini-framework
```

## Example Application

A simple Todo application is included as a demonstration of how to use this framework. This example showcases:

- Basic routing
- Data and States handling
- View rendering

To run the example:

```bash
# Start the application
npm start
```

Visit `http://localhost:3000` to see the Todo application in action.
